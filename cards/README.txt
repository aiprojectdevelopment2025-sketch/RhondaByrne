DAILY MANIFESTATION — 7-DAY DEMO
================================
This package contains your seven original uploaded card images.

QUICK PREVIEW
1. Unzip the downloaded package.
2. Open index.html in a desktop browser to preview the design. For best results, use a web server (see below).

FREE SHAREABLE LINK WITH GITHUB PAGES
1. Create a free account at https://github.com/ if needed.
2. Create a new PUBLIC repository (e.g. daily-manifestation-demo).
3. Upload the CONTENTS of this unzipped folder to the repository root (index.html, app.js, sw.js, manifest.webmanifest, both icons, and the cards folder). Do not upload only the ZIP.
4. In the repository open Settings > Pages. Choose Deploy from a branch, main, /(root), then Save.
5. Wait for publishing. GitHub will show your public URL (usually https://YOUR-USERNAME.github.io/REPO-NAME/).
6. Open that URL on iPhone or Android; optionally add to Home Screen from your browser's Share/Menu controls.

DEMO RULES
- On the first reveal, the app randomly orders all seven cards.
- Day 1 starts on the first reveal date, based on the device's local calendar.
- Each subsequent calendar day reveals the next card in that randomized order.
- No card repeats; after day 7, the demo is marked complete.
- Preview All 7 Cards is always available and does not affect the daily draw.
- Progress is saved in that browser/device using localStorage. Different devices start independently.
- Clearing site data or using private browsing may reset the journey.
- The website includes a service worker for offline use after the first online visit on HTTPS.

IMPORTANT
Your images are published publicly if you use a public GitHub Pages repository. Only publish artwork you have permission to share. This package does not verify image licensing or ownership.
